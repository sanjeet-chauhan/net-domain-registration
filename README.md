## What Is a .net Domain?

.net began as the extension for network providers and ISPs. Today it is used by tech companies, developers, SaaS platforms, IT services and any business that works online.

It launched in 1985 and is managed by Verisign. Anyone in the world can register one.

| Detail | .net |

| Managed by | Verisign Inc. |
| Launched | 1985 |
| Who can register | Anyone worldwide |
